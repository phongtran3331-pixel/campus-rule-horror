## 日常更新（改完代码）

```bash
# 1. 本地打包并上传（在仓库根目录执行）
git archive --format=tar.gz -o .deploy.tgz main
scp -i ~/.ssh/atto_deploy .deploy.tgz Administrator@192.144.254.107:C:/atto/app.tgz

# 2. 服务器端解压重建（SSH 上去执行）
tar -xzf C:\atto\app.tgz -C C:\atto\app --strip-components 0   # 先清空 C:\atto\app
# npm ci + 构建见下

# 3. 重建依赖并构建客户端
cd C:\atto\app
npm ci --no-audit --no-fund
npm run build

# 4. 重启服务
schtasks /Run /TN "atto-boot"
```

注意：tar 解压对中文文件名不兼容（docs/output 下的中文文件会跳过，不影响运行；
运行所需文件全为 ASCII 路径）。如需完整同步中文文件，单独 scp。

## 服务管理（SSH 上去后）

```powershell
schtasks /Run /TN "atto-boot"                    # 启动/重启两个服务
Get-Content C:\atto\logs\game.log -Tail 30       # 游戏服务日志

Get-Process node                                 # 应有 3 个 node（tsx 父+子、静态服务）
```
