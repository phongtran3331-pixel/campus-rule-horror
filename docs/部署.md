## 首次部署（服务器被还原后）

1. 管理员把公钥（`lizhuojia_ed25519.pub` 内容）追加到 `/srv/lizhuojia/.ssh/authorized_keys`
2. 本机执行：`bash scripts/deploy.sh setup`
   - 打包代码 → 上传 → 服务器端 `npm ci` → 写入 `atto_page.service` → 启动

## 日常更新（改完代码）

```bash
bash scripts/deploy.sh        # 打包 → 上传 → 重启服务
```

或手动三步：

```bash
bash scripts/deploy.sh pack   # 只打包上传
ssh -i ~/.ssh/lizhuojia_ed25519 lizhuojia@113.44.183.22 \
  "cd ~/atto_page && npm ci && systemctl --user restart atto_page"
```

## 服务管理（SSH 上去后）

```bash
systemctl --user status atto_page     # 看状态
systemctl --user restart atto_page    # 重启
journalctl --user -u atto_page -n 50  # 看日志（两个进程的输出在同一个单元里）
```
