## 一、小场景 / 单场景提示词（学校大门、小树林……图书馆等非教学楼场景用）

```
你是校园规则怪谈生存游戏《自管委》的文本写手。请为以下探索节点树写事件文本。

【世界背景】
玩家是刚转进这所学校的学生。转学当晚收到无名短信：务必通读学生手册。
学校由"学生自主管理委员会"（自管委）管理，委员会的成员就混在学生中间，
白天巡视、记录违规，夜晚按校规处分人。白天玩家探索校园搜集物资活下去，
每天中午在食堂集会讨论并投票，把委员会成员投出去。
这所学校的怪谈是日常化的：所有反常都以最正常的口吻出现，没人觉得不对。

【节点树说明】
X1 = 场景「<场景名>」；P = 探索子位置；Y = 事件节点（每个 Y 是一个选项）。
结构：进入 P 先看到 situation（场景描述），P 的子 Y 是第一层选项；
选中某个 Y 后显示它的 result（结果文本），该 Y 的子 Y 是之后出现的下一层选项；
无子 Y 则事件链收束（END）。同一父节点下的多个子 Y = 并列选项，写同一局面的不同走向。

【每个节点要写什么】
- 每个 P：situation（30~60 字，玩家进入该子位置时看到的场面）
- 每个 Y：choice（选项文本，≤15 字，动词开头短语，如"翻开讲台抽屉"）
        + result（结果文本，15~60 字，遵循风格铁律；无子 Y 的收束链 result 要有结尾感）

【文本风格铁律】
1. 只写看得见、摸得着、听得见的，不解释、不总结、不点破。
2. 不写"你感到/你意识到/你知道"；感受落在身体上（后颈发凉、手心出汗、耳内嗡鸣）。
3. 长短不一：15~60 字，多数 20~40 字，允许十来字的短句，禁止条条 30 字。
4. 角度轮换：纯感官 / 动作后果 / 对话碎片（纸条、墙上字、广播半截话）/ 规则文本引用 / 旁人反应。
5. 口吻轮换：冷静白描约六成、日常碎碎念一成半、校园黑色幽默一成半、温情怅惘一成。
6. 禁用："仿佛/似乎/宛如"堆砌；每条都"但/却"反转；排比对仗；
   "有什么东西在暗处注视着你"；结尾总结句；每句一个"像"；游戏数值词（HP/SAN/AP）。
7. 不出现"自管委""理事长"剧透字样；可用袖章、值周生、广播、通报等元素。
8. 恐怖是 understated 的：一条链里最多一两条直接惊悚，其余是安静的不对劲。
9. 掉落用 {} 标注（见下方【机制标注】），物品名必须从《物品 Wiki》中选并带编号；
   每 5~8 条 result 最多一个掉落。
10. 文本不承担谜题功能：本游戏是对抗性推理，玩家的对手是其他玩家，不是文本。
    写"发生了什么"（可直接验证的事实：灯闪了、东西不见了、日期是明天的），
    不写"意味着什么"。禁用引导深究的句式："每次看形状都不太对""多出来的那个字"
    "背面还有一层""它在你手心里慢慢转了个向""绳子的另一头不知通向哪里"。
    结果的落点是玩家的处境和物资，不是"发现秘密"。玩家读完就走，不需要回头重读，
    更不需要对着一句话琢磨它暗示什么。
11. 位置断言禁令：禁止写"有个背影拐过弯""刚才有人来过这间屋子""跑道上站着
    一个人"这类断言其他玩家实时位置/存在/身份的句子。涉及"看见人"一律改成
    非断言景物（"跑道上有串脚印，还没干透"）或删掉。
12. 时间痕迹用词表（详见风格指南第八章）：还温着/冒热气≈1 分钟内；没干透/
    印子还新≈本时段内；凉了/结了层皮/积灰≈更早。同一链内口径一致。
13. 痕迹纪律：痕迹理事长也留得出来（禁袖章、值周记录这类理事长专属物证）；
    痕迹只证明"有人来过"，不给身份线索（禁写着全名的纸条）。每个 P 留 1~4 条。
14. 时钟绑定禁令：禁"现在是上课时间""天黑前"这类与时钟绑定的断言，
    用不依赖时钟的景物表达时间（"旗杆的影子挪了一指宽"）。
15. 幻觉文本与真实文本完全同构：同样的句式、口吻、长度，不排版标记、不文风突变；
    幻觉内容违反现实但不违反风格。

【深入探索（答题节点）】
树里 quiz=true 的 Y 是答题节点（预标记：叶节点、深链、分散在不同子位置），
在 result 末尾用三段式 {} 标注（见【机制标注】），其余 Y 不带答题标注。
- 静态题（脑筋急转弯/高数/校史冷知识）：预设正确选项。动态局势题（如"现在还有几个人
  活着"）：无预设答案，程序按答题瞬间的真实局势结算——答题者本人计 1，每多一名符合
  题面条件的玩家 +1。
- 动态题规则类型只能是 "dynamic_alive"（存活人数）、"dynamic_room"（同房间人数）、
  "dynamic_report"（当日通报次数）、"dynamic_visit"（今日到访本节点的去重人数，
  含答题者，每天重置）四者之一，且题面必须与类型对得上，禁止发明其他 dynamic 值。
  到访题只放低频节点，选项覆盖合理人流上限（一般 1~4）。
- 出题前先想清楚：这道题的答案玩家正常途径能不能查到（动态题的乐趣就在"赌一把"）；
  静态题禁止网上一搜就有的烂题。
- quiz 节点和高价值掉落别埋深度 4 以下的深链（一天 10 AP 只够走一条，埋了也白写），
  深度 2~3 为宜。

【机制标注（{} 统一说明，替代旧 [[ ]]、【】、quiz 字段）】
- 获得物品：result 末尾写 {获得:名称(段#编号)}，编号查 output/wiki_index.json
  （普=普通、高=高价值、关=关键、耗=消耗品）。例：{获得:旧饭票(普#40)}
- 状态改变：choice 末尾写 {状态:行动值±n，饥饿值±n，健康值±n，精神值±n}。
  例：运动一下{状态:行动值-2，饥饿值-35，健康值+10，精神值+20}
- 操作/界面：{操作:打开背包选择物品回收}、{操作:打开售货机界面}
- 答题：result 末尾写 {答题:题目|选项:A,B,C|规则:类型=说明}；
  静态题规则写 "规则:静态题，预设正确选项=第N项"。
- 动态注入：result 中允许 {今日到访}（白名单仅此一个，禁止自创），
  程序替换为实时数字，用于登记本、计数板这类"记录人数"的物件。
- 掉落 5~8 条最多一个；先到先得场景另写 result_taken 空态文本。

【空态文本（result_taken）】
凡 result 含 {获得:} 的 Y，必须额外写 result_taken（15~60 字，同样守全部铁律）：
来晚版，落点是扑空+痕迹（时间词表合规），与 result 各自独立成立，禁止复读。
"Y9": {"choice": "别碰它，退开",
  "result": "你后退时踩到了什么。低头看，是一张旧饭票，面额栏里印着「明天」。{获得:旧饭票(普#40)}",
  "result_taken": "你后退半步。地上空空的，只剩一圈浅浅的压痕，像被谁抢先捡走了。"}

【冲突道具】
掉落池固定 5~8% 给冲突道具：描述只写形态手感（"沉甸甸的，一头粗一头细，握把上
缠着新胶布"），不写用途。占比不足 5% 视为不合格。

【玩法覆盖树】
树是起手稿不是合同：功能性场景按玩法需要写几个选项就写几个（如宿舍白天只有
「睡一觉{状态:行动值-1，饥饿值-25，精神值+30，健康值+5}」一个事件选项），
想加节点直接在文本里续编号添加，程序按文本实际结构解析。

【风格示例】
冷静白描：值日表贴在门后。今天的日期被人用指甲划掉了。
碎碎念：自动售货机又卡货了。你拍了两下，它掉出来两瓶——都不是你按的那个。
玩梗：小票上只有一行：确认单。买没买东西不重要，重要的是它确认你来过。
温情：课桌右下角刻着"加油"。刻痕很旧，后来的无数道刻痕都绕着它走。
动作后果：你把柜门关上了。隔了两秒，里面传来翻书声。

选项+结果示范：
choice「查看铁器堆」-> result「哑铃按重量排成一列。中间缺了一个位置，灰里有新近压过的痕。」
choice「先跑为敬」-> result「你退到门口。身后的铁器轻轻响了一声，然后安静了。」
situation 示范（P=器械区）：「器械区的灯坏了一半。铁器堆在墙角，谁用完都没放回去。」

【输出格式】
只输出一个 JSON 对象，含两个键，不要输出任何其他内容：
{
  "situations": {"P1": "……", "P2": "……"},
  "events": {"Y1": {"choice": "……", "result": "……"}, "Y2": {"choice": "……", "result": "……{获得:半截粉笔(普#1)}", "result_taken": "……（来晚版，result 含 {获得:} 必写）"}, "Y3": {"choice": "……", "result": "……{答题:现在还有几个人活着？|选项:3,5,7,9|规则:dynamic_alive=存活人数，答题瞬间结算}"}}
}
编号与树一致（玩法覆盖场景除外）。答题用 {} 三段式标在 result 里，不带独立 quiz 字段；
result_taken 只出现在 result 含 {获得:} 的 Y 上。

【节点树 JSON】
<粘贴该场景 campus_tree.json 中 "p" 数组（名称、编号）与 "y" 数组（编号、父子关系、深度）>
```

## 三、物品描述重写提示词（共 6 次）

```
你是校园规则怪谈游戏《自管委》的物品文案写手。请重写下列物品的描述列。

【铁律】
1. 只重写"描述"，物品名、价值、负重、效果、来源一律不动。
2. 描述长短不一：8~50 字自由跨度。小垃圾写得敷衍甚至吐槽，贵重物品写得郑重。
3. 角度按物品气质选：外观写触感与痕迹；吃的写味道与后果；规则类物品直接引用文本。
4. 只写看得见摸得着的，不解释不点破；禁用"仿佛/似乎"堆砌和"但/却"式反转。
5. 关键道具的描述保留用途信息，但一句话带过，不写成说明书。
6. 口吻：冷静白描为主，允许少量校园黑色幽默。

【重写示例】
旧：边缘磨圆了，图案只剩模糊的轮廓。放在桌上，过一阵子会变成背面朝上。
新：磨得只剩一圈边。你把它立在桌上，去上了个厕所，回来它倒了，背面朝上。

旧：喷出来有很重的草药味。喷过的地方，蚊子不落。
新：味儿冲得呛眼。喷过之后蚊子确实不来了——别的东西也没有。

【输出格式】
只输出 JSON 数组：[{"物品": "……", "描述": "……"}, …]，顺序与输入一致。

【本批物品】
<粘贴原 Wiki 对应表格行（保留价值/负重/效果/来源列供参考）>
```

分批：普通物品 #1~50、#51~100；高价值 30 条一次；关键道具 6 条一次；消耗品 #1~20、#21~40。

## 四、验收清单（每批输出后自查）

- [ ] 每条 15~60 字？（抽查十条量一下）
- [ ] 没有任何一条以"这一切/你感到/有什么东西"开头或结尾？
- [ ] "仿佛/似乎/宛如"全批 ≤ 2 次？
- [ ] 十条抽查里没有两条是同一个句式？
- [ ] {获得:} 只出现在 1/5~1/8 的 result 中，且名称+编号都能在 wiki_index.json 里查到？
- [ ] JSON 能被 `json.loads` 解析；events 覆盖本批全部 Y 编号、situations 覆盖全部 P 编号，无遗漏？
- [ ] choice 全部 ≤15 字且动词开头？抽查十条 result 都在 15~60 字？
- [ ] 无引导深究句式（"多出来的""每次看都不太对""背面还有一层""不知通向哪里"等）？随机抽 10 条，逐条问"这是在陈述事实还是在诱导解读"，一条诱导解读的都不该有？
- [ ] 答题：树里 quiz=true 的 Y 都在 result 末尾写了 {答题:…|选项:…|规则:…} 三段式？规则类型是四个 dynamic 值之一或"静态题，预设正确选项=第N项"？普通 Y 一律没带答题标注？
- [ ] 空态文本：凡 result 含 {获得:} 的 Y 都有 result_taken 且不含 {获得:}？两条文本各自独立成立？
- [ ] 位置断言：全批搜"背影/有人来过/站着一个人/窗户外"等，一条断言实时位置的都没有？
- [ ] 时间词表：抽查含痕迹词的 5 条，"还温着/没干透/积灰"等用词与所在链口径一致？无"现在是上课时间""天黑前"类时钟绑定句？
- [ ] 痕迹纪律：无袖章、值周记录、写着全名的纸条这类身份线索物证？
- [ ] 冲突道具：本批掉落中形态手感向（不写用途）的占 5~8%？
- [ ] 占位符：全批搜 { ，动态注入只允许 {今日到访} 这一种，机制标注只有 获得/状态/操作/答题 四类，其余一律打回？
- [ ] 物品批次：价值/负重/效果/来源列零改动？

## 五、常见翻车与对策

| 翻车 | 对策 |
|---|---|
| 输出到一半截断 | 按 Y 编号区间让它续写，或减小批次 |
| 条条都是"XX。但/却 YY。" | 把风格示例换成你满意的上一批随机抽 5 条喂回去 |
| 玩梗过多变喜剧 | 明确"黑色幽默全批不超过一成半"，示例里删掉最搞笑的那条 |
| 物品名与 Wiki 对不上（掉落标记失效） | 要求输出前先列出本批用到的物品名清单自查 |
| 教学楼三座写得一样 | 每座开头加一句楼格提示（A 老旧墙皮、B 高层灯坏、C 实验室），并要求引用楼格细节 |
| 答题规则写成乱造 dynamic 值 | 明确"只有 4 个 dynamic 值可选"，报错后让它只重输出该条的 result |
