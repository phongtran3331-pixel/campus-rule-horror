# 《校园规则怪谈》文本风格指南（定稿 v1.0）

> 适用范围：全部探索事件文本（Y 节点）、物品描述重写。
> 一句话原则：**只写现场，不解释现场。**

---

## 一、基调

这所学校怪，但没人觉得它怪。所有不正常的东西都以最正常的口吻写出来。
恐怖感来自"细节对不上"，不来自形容词。玩家后背发凉应该是读完之后的事，不是读的时候。

**对抗性游戏特调（很重要）**：这是人和人斗的游戏，玩家的心力要花在读其他玩家身上，不是解读环境。
所以探索文本**不承担谜题功能**：

- 写"是什么"，不写"意味着什么"。反常直接摆出来，一句话说完，不暗示背后有秘密。
- 禁用一切引导深究的句式："每次看形状都不太对""多出来的那个字""背面还有一层""像是想告诉你什么"——这类钩子会把玩家拽进解谜心态。
- 结果文本的落点优先是**处境和物资**（你获得了什么、你现在在哪、接下来方不方便），不是"你发现了一个秘密"。
- 怪谈质感保留，但每条读一遍就完，不需要记笔记、不需要联想。玩家中午讨论时最多说一句"我在保安室看到个怪东西"，而不是拿它当证据推理。
- 选项写动作和应对（"放回去""绕开走""先离开"），不写调查和研究口吻（"研究一下刻痕"×）。

## 二、五条铁律

1. **只写看得见、摸得着、听得见的。** 不写"你感到""你意识到""你知道"。感受可以写，但必须落在身体上：后颈是凉的、手心在出汗、耳朵里有一层嗡。
2. **不解释、不总结、不点破。** 不写"这一切太奇怪了""似乎有什么东西"。东西写出来了，像不像、是不是，让玩家自己判断。
3. **长短不一。** 15~60 字，绝大多数 20~40 字。允许偶尔一句话只有十来个字（"讲台上有半杯水。还是温的。"），也允许偶尔写到五六十个字。**绝对不要每条都 30 字左右——那是 AI 味的第一来源。**
4. **角度轮换。** 同一个场景，几条事件要换着视角写：
   - 纯感官（看见的/听见的/摸到的）
   - 动作后果（你做了 X，发生 Y）
   - 对话碎片（墙上的字、纸条、广播半截话、不知谁说的一句）
   - 规则文本引用（值日表、告示、登记表，照抄格式）
   - 旁人视角（"别人看你的时候会多看一眼"这类，少用）
5. **口吻轮换。** 不要一个腔调写到底：
   - 冷静白描（约 60%，默认腔）
   - 日常碎碎念（约 15%，学生口吻的小抱怨、小嘀咕）
   - 校园黑色幽默/玩梗（约 15%，苦中作乐，不烂俗）
   - 一瞬间的温情或怅惘（约 10%，尤其教室、树林、操场类场景）

## 三、禁用清单（AI 腔特征）

- ❌ "仿佛 / 似乎 / 宛如 / 犹如" 密集出现（全文最多出现一两次）
- ❌ 每条都用"但 / 却 / 可是"收尾反转
- ❌ 排比、对仗、四字成语堆叠
- ❌ "你感到一阵莫名的寒意/恐惧/不安"
- ❌ "有什么东西在暗处注视着你"
- ❌ 结尾总结句："这一切，太不寻常了。"
- ❌ 每句一个"像"字比喻
- ❌ 直接出现游戏数值词：HP / SAN / AP / 行动值（写"腿发沉"不写"行动值不足"）

## 四、示例（照这个感觉写）

**冷静白描**
> 值日表贴在门后。今天的日期被人用指甲划掉了。

> 讲台上有半杯水。还是温的。

**日常碎碎念**
> 自动售货机又卡货了。你拍了两下，它掉出来两瓶——都不是你按的那个。

**黑色幽默 / 玩梗**
> 小票上只有一行：确认单。你确认了什么不重要，重要的是它来确认你了。

> 广播响了：请没到的同学抓紧时间，不要到场。

**温情 / 怅惘**
> 课桌右下角刻着"加油"。刻痕很旧，后来的无数道刻痕都绕着它走。

**对话碎片 / 规则引用**
> 墙上贴着告示：晚自习期间，请保持安静，即使只有你一个人。

**动作后果**
> 你把柜门关上了。隔了两秒，里面传来翻书声。

## 五、物品描述重写专项规则

在以上铁律基础上：

1. 保留原 Wiki 的物品名、价值、负重、效果、来源，**只重写"描述"列**。
2. 描述长度跨度拉大：最短的可以 8~10 个字（"缺了三颗齿。梳头会多几根别人的头发。"），最长的可以到 50 字以上。高价值物品可以写得郑重，小垃圾可以写得敷衍甚至吐槽。
3. 角度按物品气质选：外观党（文具、饰品）写触感与痕迹；吃的写味道和后果；规则类物品（值日表、袖章）直接引用文本最有味道。
4. 关键道具（钥匙、杠铃杆、通行卡等）描述里保留用途信息，但不写成说明书，一句话带过。
5. 玩梗比例比普通事件略高（学生捡到东西的口吻），严肃物品（金戒指、名牌钢笔）保持克制。

**重写示例**

| 物品 | 旧（AI 味：均匀、必反转） | 新 |
|---|---|---|
| 磨损的硬币 | 边缘磨圆了，图案只剩模糊的轮廓。放在桌上，过一阵子会变成背面朝上。 | 磨得只剩一圈边。你把它立在桌上，去上了个厕所，回来它倒了，背面朝上。 |
| 超市小票 | 字迹褪得看不清。商品栏只有一行字：确认单。 | 就一行：确认单。买没买东西不重要，重要的是它确认你来过。 |
| 翡翠吊坠 | 对着光看，里面像封着一小片树叶。贴身的时候是温的。 | 光一透，里面封着片叶子。贴着心口放，冬天也是温的。卖家说是残次品。 |
| 驱蚊水 | 喷出来有很重的草药味。喷过的地方，蚊子不落。 | 味儿冲得呛眼。喷过之后蚊子确实不来了——别的东西也没有。 |
| 半块橡皮 | 半块橡皮，指印陷得很深。用它擦过的纸面会留一个浅窝，大小跟拇指差不多。 | 被人攥得变了形。擦字倒是干净，就是纸会留个浅浅的指窝。 |

## 六、事件文本输出约定（选项 + 结果 结构）

每个节点不是一段连续文本，而是**选项驱动的分支结构**：

- **P（子位置）= 场景描述 `situation`**：玩家进入该位置时看到的一段话，30~60 字，定场用。
- **Y（事件节点）= 选项 + 结果**：
  - `choice`：选项文本，**不超过 15 字**，动词开头的短语（"翻开讲台抽屉""跟上去看看""装作没听见"）；
  - `result`：选中后发生的文本，15~60 字，遵循前五章全部风格铁律。
- **Y 的子节点 = 该结果之后出现的下一层选项**。有子 Y 就继续选；无子 Y（END）则事件链收束，result 写得有收束感。
- 同一父节点下的多个子 Y = 并列的可选项，写成同一局面的不同走向。
- 每个子位置（P）至少有一条选项链；选项总数就是 Y 的数量，**一条都不许漏**。

程序回填格式（JSON）：

```json
{
  "situations": {"P1": "器械区的灯坏了一半。铁器堆在墙角，谁用完都没放回去。", "P2": "……"},
  "events": {"Y1": {"choice": "查看铁器堆", "result": "哑铃按重量排成一列。中间缺了一个位置，灰里有新近压过的痕。"}, "Y2": "……"}
}
```

- 允许在 result 中嵌入掉落标记 `[[物品名]]`（物品名必须从《物品 Wiki》里选），程序会将其剔除并把该物品加入掉落。每 5~8 条 result 最多用一个标记，别条条掉东西。
- 不出现"自管委""理事长"字样的剧透；可以出现"袖章""值周生""广播"这类元素。
- 选项文本可以玩梗、可以口语（"先跑为敬"），但同一批选项别都是同一种句式。

## 七、深入探索（答题节点）

挑战类事件链的末端挂一个**答题节点**：出题 → 玩家选项作答 → 对/错结算。

**两类题目：**

1. **静态题**：脑筋急转弯、高等数学、校史冷知识。设计时预设正确选项（`answer` 为选项下标）。
2. **动态局势题**：如「现在还有几个人活着」「这个房间里现在有几个人」「今天广播通报过几次」。**没有预设答案**，以答题提交那一刻的真实局势结算。计数标准：**答题者本人计 1，每多一名符合题面条件的玩家 +1**，即正确答案 = 触发瞬间的真实计数。

**结算规则：**

- 答对：奖励**高价值物品**（从《物品 Wiki》高价值栏选，不用 `[[ ]]` 标记，由程序按答对发放）。
- 答错：惩罚，扣 HP / SAN（数额由数值策划定，建议 10~20）。
- 每玩家每题**限答一次**；答错后该题对本玩家关闭，禁止反复试错刷题。
- **奖励限量**：每道题全局限前 N 名答对者发高价值物品（建议 N=3），之后答对只给小额物资。先到先得，晚到吃亏——这本身就是对抗性的一部分：谁先在探索上花时间，谁占便宜。

**JSON 扩展（quiz 字段，仅答题节点有）：**

```json
"Y42": {
  "choice": "回答墙上的问题",
  "result": "粉笔灰聚成一行字：「现在还有几个人活着？」",
  "quiz": {
    "q": "现在还有几个人活着？",
    "options": ["3", "5", "7", "9"],
    "answer": "dynamic_alive"
  }
}
```

- 静态题：`"answer": 2`（options 下标，从 0 开始）；
- 动态题：`"answer": "dynamic_alive"`（存活人数）/ `"dynamic_room"`（同房间人数）/ `"dynamic_report"`（当日通报次数）——局势类型从这三种里选，程序枚举，创作方出题时保证题面与类型对得上。
- `result` 仍是出题那一刻的场景文本（15~60 字，遵守前五章全部铁律）；**题目本身不写进 result，只写进 `quiz.q`**，因为选项按钮由程序渲染。

**出题要求：**

- 静态题要有"校园味"：可以是高数题、英语完形、校史冷知识、脑筋急转弯，禁止网上一搜就有答案的烂大街题。
- 动态题要有信息价值：答对等于免费获得一条 normally 要花钱/花 AP 才能查的局势信息（存活名单长度、房间里有没有人），答错白挨罚——这制造"要不要赌一把"的决策。
- 每 10~15 个 Y 节点最多挂 1 个答题节点，探索主基调仍是翻找物资，答题是点缀。
