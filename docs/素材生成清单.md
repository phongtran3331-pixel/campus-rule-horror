# 《校园规则怪谈：自管委》素材生成清单 v1.0

> 用途：交付专业 AI 绘图工具（Midjourney / Stable Diffusion / 即梦 / DALL·E 等）批量产出美术素材。
> 交互文案文本已有底稿（见 `manual/main.tex` 附录 A、B），本清单不重复文案内容，只列**需要出图的素材**与提示词。
> 总量预估：**地图/场景 34 张、图标 42 枚、NPC 立绘 6 张、UI 设计稿 10 屏**。

## 〇、统一规范（所有提示词共用，先读这里）

### 0.1 风格锚点（STYLE ANCHOR）

所有提示词前缀统一拼接以下风格段，保证全套素材风格一致：

```
2D game art, rule-based horror campus atmosphere, eerie mundane school life, muted cold blue-grey palette with desaturated teal accents, soft volumetric light, slight film grain, subtle dread, no gore, no text, no watermark, no logo
```

中文理解：2D 游戏美术、规则怪谈式校园氛围、日常感中透着不对劲、低饱和冷灰蓝主色 + 暗青点缀、柔和体积光、轻微胶片颗粒、**无血腥**、**画面中不要出现任何文字**（文字一律由前端叠加，AI 生成的中文字必翻车）。

### 0.2 负面提示词（Negative Prompt，SD 系必填）

```
text, letters, chinese characters, watermark, logo, signature, blood, gore, extra limbs, deformed, blurry, oversaturated, cute chibi, anime sparkle
```

### 0.3 命名与规格

| 类别 | 尺寸 | 格式 | 命名 |
|---|---|---|---|
| 大地图/场景底图 | 1920×1080 或 2048×2048 | PNG/JPG | `map_<节点id>[_night][_offline].png` |
| 楼层平面图 | 1600×1200 | PNG | `floor_<楼>_<层>.png` |
| 图标 | 512×512 | **PNG 透明底** | `icon_<名称>.png` |
| NPC 立绘 | 1024×1536 | PNG 透明底 | `npc_<名称>.png` |
| UI 设计稿 | 1170×2532（手机竖屏） | PNG | `ui_<编号>.png` |

### 0.4 一致性技巧

1. **垫图锁风格**：先用总览图（M1）定稿一张满意图，后续所有场景图以它为 image prompt / 参考图，风格权重拉满。
2. **种子记录**：每张定稿图记录 seed，同节点三态（白天/夜晚/断网）用同 seed 微调。
3. **图标统一**：全部图标用同一段风格锚点 + "flat icon design, centered, single object, dark background circle" 生成，再统一加同色描边。
4. **理事长视觉**：涉及理事长阵营的素材（暗纹徽章等）只在结算/身份揭晓界面使用，平时**不得**出现在任何公共素材中。

## 六、产出顺序建议

1. **第一批（定风格）**：M1 总览图三张 → 选一张定全局。
2. **第二批（核心循环）**：M2-01/02/10/12（宿舍、食堂、社区、行政楼）+ 数值图标 5 枚 + UI-01/02/04。
3. **第三批（完整探索）**：其余 M2、M3 楼层图、道具图标全套。
4. **第四批（氛围与揭晓）**：M4 特写、NPC、UI-05/06/09/10、理事长身份图标（保密）。

> 交付检查：每张图过一遍"三无一致"——无文字、无水印、无血腥；与 M1 风格一致。
